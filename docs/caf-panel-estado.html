¿Cuál es cuál? — Los 4 cores Nivel 1 hacen cosas muy distintas: Medidor IA = wallet prepago (saldo en centavos, authorize/finish/credit). Hub-Pasarelas = gateway de pago real (Conekta) — cobra con tarjeta. Finanzas-Core = libro contable (ledger de asientos contables en MXN, fuente de verdad de ingresos). Centro-Mensajes = notificaciones (email/WhatsApp) vía plantillas. El CAF (Nivel 2) orquesta los 4 en cada operación.

NIVEL 1 — Cores (API-only · sin UI · sin auth humano)
💳 Medidor IA
medidor.inovaweb.com.mx
Qué hace: mantiene wallets prepago en centavos MXN. Mide cada llamada LLM y cobra el costo. Es la fuente única de saldo y consumo de IA.
CAF llama con scope ADMIN:
POST /v1/wallets POST /v1/wallets/{id}/credit GET /v1/wallets/{id}/balance
Wallet prepago
💰 Hub-Pasarelas
hub.inovaweb.com.mx
Qué hace: procesa pagos reales con tarjeta vía Conekta. Cobra al cliente en su tarjeta bancaria. Confirma el pago con un webhook payment.paid.
CAF llama para cobrar:
POST /v1/charges ← webhook payment.paid
Gateway de pago
📒 Finanzas-Core
finanzas.inovaweb.com.mx
Qué hace: es el libro contable (ledger). Guarda asientos contables de cada ingreso en MXN. El CAF lo registra después de cada pago confirmado. Scraping también postea asientos de consumo IA directo.
CAF llama para registrar:
POST /v1/entries GET /v1/balance
Libro contable
✉️ Centro-Mensajes
mensajes.inovaweb.com.mx
Qué hace: envía emails y WhatsApp por plantilla. El CAF lo invoca en cada evento relevante (activación, pago, vencimiento, etc.).
CAF llama para notificar:
send_email (template) send_whatsapp (template)
Notificaciones
